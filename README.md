# توثيق مساجد مكتب أوقاف القره بوللي

تطبيق ويب عربي (RTL) للهاتف أولاً، يستخدمه موظفو مكتب أوقاف القره بوللي لتوثيق المساجد ميدانياً: الموقع الدقيق، الاسم والمحلة، الصور، ثم متابعة نشرها في خرائط جوجل وتصدير تقرير Excel.

الموقع: https://abdarhemsheet-max.github.io/qarabulli-mosques/

---

## كيف يعمل

- **الخريطة** (الشاشة الرئيسية): كل مساجد القره بوللي ظاهرة — الأخضر موثّق، والرمادي موجود في OpenStreetMap ولم يُوثَّق بعد. بحث بالاسم أو المحلة، وزر «موقعي».
- **توثيق مسجد**: دبوس ثابت في منتصف الشاشة ويحرّك الموظف الخريطة تحته حتى يكون فوق المسجد ← «هنا المسجد» ← نموذج قصير (الاسم، المحلة بضغطة، الكاميرا، تفاصيل اختيارية) مع تنبيه التكرار.
- **النشر في خرائط جوجل**: بعد الحفظ تظهر خطوات موجّهة (نسخ الاسم ← فتح المكان في جوجل ← مشاركة الصور ← «أرسلته»)، وتُحفظ حالة كل مسجد (لم يُرسل / بانتظار جوجل / ظاهر) مع اسم من أرسله ووقته. جوجل لا تسمح بالنشر الآلي، لذلك يتم الإرسال من تطبيق خرائط جوجل نفسه.
- **المساجد**: قائمة ببحث وفلاتر سريعة (توثيقاتي، لم يُرسل لجوجل، ...) وتصدير Excel/KML/CSV.
- **الإدارة** (للمدير): إحصاءات، تقدّم النشر في جوجل، عمل كل موثِّق، حسب المحلة، إضافة الموظفين، وتقرير Excel.
- **الصلاحيات**: الموثِّق يعدّل ويحذف ما أضافه فقط، والمدير يدير كل شيء. الحماية مطبّقة في قاعدة البيانات (Row Level Security).

## التقنيات

React 19 · Vite · Tailwind 4 · Leaflet (OpenStreetMap + Esri) · Supabase (Postgres + Auth + Realtime) · xlsx-js-style · GitHub Pages.

## هيكل المشروع

```text
src/
├── App.tsx                      # الدخول، تحميل البيانات، التبويبات
├── pages/
│   ├── MapPage.tsx              # الخريطة، البحث، وضع تثبيت الدبوس
│   ├── ListPage.tsx             # قائمة المساجد والفلاتر والتصدير
│   ├── AdminPage.tsx            # لوحة المدير والموظفون
│   └── LoginPage.tsx
├── components/
│   ├── map/MosqueMap.tsx        # خريطة Leaflet
│   ├── map/LocationCard.tsx     # طلب إذن الموقع
│   ├── MosqueFormSheet.tsx      # نموذج التوثيق
│   ├── MosqueSheet.tsx          # بطاقة المسجد
│   ├── GoogleMapsPublishCard.tsx# خطوات النشر في جوجل
│   └── ui/                      # BottomSheet, ConfirmDialog, GoogleStatusBadge
├── lib/
│   ├── supabase/                # الاتصال، الدخول، المساجد، الإعدادات
│   ├── location/                # إذن الموقع وتتبع GPS
│   ├── export/                  # Excel (تحميل عند الطلب) و KML/CSV
│   ├── utils/osmMosques.ts      # مساجد OpenStreetMap (قائمة مدمجة + تحديث حي)
│   └── demo.ts                  # وضع معاينة محلي ببيانات تجريبية
public/osm-mosques.json          # قائمة مساجد القره بوللي من OpenStreetMap
supabase/migrations/             # الجداول والصلاحيات
```

## التشغيل المحلي

```bash
npm install
```

```bash
npm run dev
```

معاينة الواجهة ببيانات تجريبية بدون تسجيل دخول (محلياً فقط): افتح `http://localhost:3000/?demo=1`.

## قاعدة البيانات (Supabase)

- المشروع: `htfyhhkvqxdjpdjtpnff`. الرابط والمفتاح العام في `supabase-config.json` (المفتاح العام آمن للنشر).
- تطبيق التغييرات: `supabase link --project-ref htfyhhkvqxdjpdjtpnff` ثم `supabase db push`.
- كلمة مرور قاعدة البيانات محفوظة محلياً في `.env.local` فقط (لا تُرفع على GitHub).

## النشر

كل `push` إلى `main` يبني الموقع وينشره على GitHub Pages تلقائياً (`.github/workflows/deploy.yml`).
